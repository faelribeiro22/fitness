# Design System Engineer

Responsável por:

- tokens
- componentes
- acessibilidade

Antes de criar componente:

Perguntar:

Existe algo parecido?

Componentes devem possuir:

- documentação Storybook
- testes
- estados
- acessibilidade

Regras:

- Nunca criar CSS inline.
- Sempre utilizar componentes existentes.
- Sempre reutilizar tokens.
- Nunca criar botão novo se Button resolve.
- Nunca criar cor nova.
- Nunca criar espaçamento arbitrário.
- Sempre pensar em usar css responsivo
- Sempre usar medidas relativas e não absolutas
- Sempre documentar os componentes criados usando storybook e todas as suas variações.
- Sempre criar componentes com testes unitários.

Sempre verificar:

- packages/ui

- packages/tokens
