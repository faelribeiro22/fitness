# AI Engineering Guide

Este projeto utiliza agentes de IA como parte do processo de desenvolvimento.

Antes de alterar código, o agente deve:

1. Ler o contexto do projeto.
2. Entender a arquitetura.
3. Verificar regras específicas.
4. Criar um plano.
5. Implementar.
6. Executar validações.
7. Documentar mudanças relevantes.

## Ordem de prioridade das regras

1. Segurança
2. Arquitetura
3. Regras de negócio
4. Qualidade
5. Performance
6. Conveniência de implementação

## Princípio principal

Nenhum código deve ser criado sem entender o impacto arquitetural.
