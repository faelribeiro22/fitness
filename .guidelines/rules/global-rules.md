# Global Rules

## Código

Sempre priorizar:

- legibilidade
- simplicidade
- manutenção

Evitar:

- código duplicado
- abstrações prematuras
- arquivos gigantes

## Antes de criar algo novo

Verificar:

Existe componente?
Existe util?
Existe package compartilhado?

## Documentação

Toda decisão arquitetural deve gerar ADR.
